# 시화산노회 자료 검색 (관리자 전용)

총회자료실 위쪽 검색창에 질문을 적으면, **이 컴퓨터**가 총회 헌법·규정·회의결의와
노회 회칙에서 관련 대목을 찾아 Claude에게 물어 답을 만들어 줍니다.

- 쓸 수 있는 사람: **노회장 · 서기 · 간사 · 최고관리자** (다른 회원에게는 검색창이 아예 보이지 않습니다)
- **이 컴퓨터가 켜져 있고 검색 서버가 돌아갈 때만** 검색이 됩니다.
  꺼져 있으면 검색창도 나타나지 않으므로, 다른 분들이 헛되이 기다릴 일이 없습니다.

## 쓰는 법

1. 이 폴더의 **`검색서버 시작.bat`** 을 두 번 누릅니다.
2. 검은 창에 "검색 서버가 켜졌습니다"가 나오면 준비된 것입니다. **창을 닫지 마세요.**
3. 홈페이지 → **총회자료실** 에 들어가면 맨 위에 검색창이 나타납니다.
4. 다 쓰신 뒤에는 검은 창에서 `Ctrl+C` 를 누르거나 창을 닫으면 됩니다.

## 자료를 새로 받은 뒤에는

총회 자료를 다시 내려받았거나 노회 회칙을 고쳤다면,
**`자료 새로 읽기.bat`** 을 한 번 실행한 뒤 검색 서버를 껐다 켜 주세요.

## 비용 관리

토큰을 아끼기 위해 이렇게 해 두었습니다.

- 작은 모델(Haiku)을 씁니다.
- 질문 하나에 자료 조각 8개만 넘깁니다. (자료 전체를 넘기지 않습니다)
- 하루 사용 한도: **한 사람 40회, 전체 150회**
- 관리자 외에는 검색창이 보이지 않습니다.

한도나 모델을 바꾸시려면 `server.js` 맨 위의 `CFG` 부분을 고치시면 됩니다.

```js
model: 'claude-haiku-4-5-20251001',   // 더 똑똑한 답이 필요하면 'claude-sonnet-5'
topK: 8,                              // 넘길 자료 조각 수
dailyLimitPerUser: 40,
dailyLimitTotal: 150,
```

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `검색서버 시작.bat` | 검색 서버를 켭니다 (평소 이것만 쓰시면 됩니다) |
| `자료 새로 읽기.bat` | 자료를 다시 읽어 색인을 새로 만듭니다 |
| `build-index.js` | 홈페이지 자료를 검색용 조각으로 나눕니다 |
| `server.js` | 질문을 받아 자료를 찾고 Claude에게 물어봅니다 |
| `index.json` | 만들어진 색인 (자동 생성, 저장소에 올리지 않습니다) |

## 준비물

- [Node.js](https://nodejs.org) (이미 설치되어 있습니다)
- Claude Code CLI — `claude` 명령이 로그인된 상태여야 합니다.
  로그인이 풀렸다면 명령 프롬프트에서 `claude` 를 실행해 `/login` 하시면 됩니다.

## 잘 안 될 때

| 증상 | 살펴볼 것 |
|---|---|
| 검색창이 안 보임 | 서버가 켜져 있는지 / 노회장·서기·간사 등급으로 로그인했는지 |
| "연결하지 못했습니다" | `검색서버 시작.bat` 창이 닫히지 않았는지 |
| "Not logged in" | 명령 프롬프트에서 `claude` 실행 후 `/login` |
| 답이 엉뚱함 | `자료 새로 읽기.bat` 실행 후 서버 재시작 |
